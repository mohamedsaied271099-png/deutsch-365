# 🇩🇪 Deutsch 365: ألماني من الصفر لـ B2 في سنة

## التكلفة
| الحاجة | التكلفة |
|---|---|
| التطبيق نفسه (من غير سيرفر) | **0** |
| الاستضافة على GitHub Pages | **0** |
| المدرس الذكي باشتراكك في Claude / ChatGPT | **0 زيادة** (إنت دافعهم أصلاً) |
| مفتاح API (اختياري) مع Haiku 5.5 | تقريباً 3–5$ في السنة كلها |

## تشغيله على الكمبيوتر
```bash
python -m http.server 8365
```
وبعدين افتح http://localhost:8365

## تشغيله على الموبايل ببلاش (GitHub Pages)
1. اعمل repo جديد على GitHub وارفع ملفات الفولدر ده.
2. Settings ← Pages ← Branch: main ← Save.
3. افتح اللينك من موبايلك، ومن قايمة المتصفح اختار "Add to Home screen". كده بقى تطبيق على الموبايل.

## أول مرة تفتحه
1. ⚙️ الإعدادات ← انسخ "تعليمات الـ Project" وحطها في Project جديد اسمه Deutsch 365 في Claude وفي ChatGPT.
2. حدد تاريخ البداية.
3. كل يوم: 📅 النهارده ← اعمل المهمة ← 🧠 راجع البطاقات ← ✔️ خلصت.

## نظام الأسبوع
قواعد ← مفردات ← تمارين ← استماع ← كتابة ← محادثة ← مراجعة واختبار

## الملفات
- `curriculum.js`: المنهج (52 أسبوع) والمدرسين والكلمات الجاهزة
- `tutor.js`: المدرس الذكي (البرومبتات + الربط بـ Claude/ChatGPT + الـ API)
- `app.js`: الواجهة والبطاقات والتقدم
- تقدمك محفوظ في المتصفح، فخد **نسخة احتياطية** من الإعدادات كل أسبوع.
